# Xbox C2 API
Reverse engineered Xbox C2 channel for authorized security testing.

## Deployment
Deployed on Railway with automatic HTTPS and scaling.

## Endpoints
- `/health` - Health check
- `/c2/exfiltrate` - Exfiltrate data
- `/c2/system` - Exfiltrate system info
- `/c2/file` - Exfiltrate file
- `/c2/credentials` - Exfiltrate credentials
- `/c2/screenshot` - Exfiltrate screenshot
- `/c2/stats` - Get stats
- `/c2/monitor/start` - Start monitoring
- `/c2/monitor/stop` - Stop monitoring
